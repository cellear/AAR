# Standee prompt for {{name}}, {{role}}

Paste into an image generator. The style matches the starter cast so the new
assistant stands beside the others without looking pasted in.

> Full-body illustration of a friendly {{role}} named {{name}}, standing,
> facing the viewer with a warm half-smile, holding one object that says what
> they do ({{prop}}). Clean digital cartoon style: soft cel shading, thin dark
> outlines, warm muted palette, no background, no text, no logo. Character
> takes up the full height of the frame. Portrait orientation. Plain white
> background so it can be cut out.

Save the result as **`avatar.png`** in this office folder, with the
background removed (transparent PNG), about **340 pixels tall** and no wider
than 260. The dashboard scales it to fit and stands it on the card's floor.
